# Archived prompts

Each gzip-compressed JSON file contains the original system and user messages for one application and condition. The `messages` object is keyed by SHA-256 of the serialized messages. The `predictions` object links model aliases, actor session IDs (or `description-only`) and run numbers to those message hashes. These messages were matched to every prediction in the packaged SQLite databases before redaction. A participant identifier was removed from one WebArena message. Its original digest remains the index key and its reviewer digest is recorded under `reviewer_digests`.

Use `python run_llm.py <application> <condition> <model> --preview` to export a readable `request.json` per case. The runner defaults to archived messages for both preview and fresh inference. `--rebuild-prompts` regenerates messages from the included templates and trace adapters. Rebuilt message digests match the saved TestReco and WebArena trace messages in the DeepSeek panel. The local QuizComp trace and description-only templates produce different digests from the archived messages. Use the default archived requests to reproduce the recorded prompt inputs with the documented redaction.
